1. **组件注册**： -
   每个Repository只允许注册与其作用域匹配的组件（即组件接口上注解的作用域必须等于当前Repository的作用域）。 -
   注册时进行作用域匹配检查，不匹配则抛出异常。
2. **组件查找**： - 每个Repository只能其作用域匹配的组件。
3. **跨层级访问**： - 只能通过父子关系向上查找，不能向下查找。 - 注册时不能跨层级注册。
